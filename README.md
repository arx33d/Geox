# GEOX

Spoof the GPS location of a phone connected to this PC — Find My, Snap Map and
every other app will see wherever you point it. Includes Trip mode that
follows a real car/bike/walk/bus itinerary, and can parse a pasted Google
Maps link.

**Start:** double-click `run_geox.bat` (self-installing — no Python needed),
then open [http://127.0.0.1:7876](http://127.0.0.1:7876).

Everything is explained in [EXPLANATION.md](EXPLANATION.md) — setup, how it
works, troubleshooting, and responsible-use notes. Read it first.
